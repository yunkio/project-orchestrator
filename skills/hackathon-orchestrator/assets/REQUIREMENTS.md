# 요구사항과 근거

메인이 관리한다. 실제 원자료와 답변을 읽은 뒤 필요한 행만 추가한다. 빈 양식은 검토 완료의 근거가 아니다.

- 현재 의도 버전:
- 마지막 대조 시점 / 코드·입력 버전:
- 확인된 규범 우선순위와 명시적 출처: 미확인

## 원자료 목록과 읽기 범위

전체 파일을 읽었으면 `전체`로 적는다. 일부만 읽었으면 절·페이지·범위를 적고 미독 부분을 남긴다. 범위 안의 각 자료는 요구 ID 또는 요구 없음/제외 이유와 연결한다. 미확인 부록·접근 불가 자료도 행에 포함한다.

| 자료 ID | 종류·위치·버전 | 실제 읽은 범위 | 미독·접근 불가 범위 / 영향 | 연결 요구 또는 요구 없음·제외 이유 |
|---|---|---|---|---|

## 조건별 추적표

근거 구분: 명시 요구 / 사용자 답변 / 현업 발언 / AI 해석·가정. 상태: 미확정 / 확정 / 구현 중 / 검증 대기 / 검증 통과 / 재검토 / 미완료 / 적용 없음. `적용 없음`에는 원문 또는 명시적 선택 근거가 필요하며, 필수 미충족을 숨기는 데 쓰지 않는다.

| 요구 ID | 원문 출처·위치 / 근거 구분 | 역할·발생 조건 / 요구 결과·금지 결과 | 통과 조건 | 의도·QNA ID | 구현·작업 ID | 검증 근거·버전 | 상태·한계 |
|---|---|---|---|---|---|---|---|

## 충돌·누락·불확실성

자료 이름이나 작성 시점만으로 우선순위를 정하지 않는다. 해결 전 영향받는 작업을 표시한다.

| 항목 ID | 상충 원문 또는 누락·미독 위치 | 영향받는 요구·작업 | QNA ID / 답변·명시적 우선순위 근거 | 처리·남은 한계 |
|---|---|---|---|---|

## 독립 감사 연결

감사 세부 보고는 고유 파일에 두고 여기에는 결과만 연결한다. 자체 점검은 독립 감사와 구분한다.

| 감사 ID·단계 | 새 맥락·원문 접근 근거 | 1차 봉인 보고·식별자 | 2차 대조 보고 | 영향 요구·처분 근거 | 상태·미검토 범위 |
|---|---|---|---|---|---|
